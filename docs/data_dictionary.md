| Column             | Type    | Description                                                    | Business Meaning |
|-------------------|--------- |--------------------------------------------------------------- |------------------|
| CustomerID        | String   | Unique identifier assigned to each customer.                   | Used to uniquely identify customers and link their records across business systems. |           
| Count             | Int64    | Number of records.                                             |       Used for counting customers in reports and aggregations. Usually equals 1 for each record. |           
| Country           | String   | Customer's country of residence.                               | Supports geographic analysis, regional reporting, and market segmentation. |    
| State             | String   | Customer's state or province.                                  | Used for regional performance analysis and operational planning. |
| City              | String   | Customer's city of residence.                                  | Enables city-level customer segmentation and marketing campaigns. |
| Zip Code          | Int64    | Customer's postal code.                                        | Used for location-based analysis and service coverage planning. |
| Lat Long          | String   | Geographic coordinates of the customer.                        | Supports geographic visualization and location intelligence. |
| Latitude          | Float64  | Latitude coordinate.                                           | Used for GIS mapping and spatial analytics. |
| Longitude         | Float64  | Longitude coordinate.                                          | Used for GIS mapping and spatial analytics. |
| Gender            | String   | Customer's gender.                                             | Used for demographic analysis and targeted marketing. |
| Senior Citizen    | String   | Indicates whether the customer is a senior citizen.            | Helps identify customer age groups for personalized products and services. |    
| Partner           | String   | Indicates whether the customer has a partner.                  | Supports customer profiling and churn behavior analysis. |
| Dependents        | String   | Indicates whether the customer has dependents.                 | Used to understand household characteristics and customer needs. |
| Tenure Months     | Int64    | Number of months the customer has been with the company.       | Measures customer loyalty and is an important predictor of churn. |
| Phone Service     | String   | Indicates whether the customer has phone service.              | Identifies customers subscribed to telephone services. |
| Multiple Lines    | String   | Indicates whether the customer has multiple phone lines.       | Helps evaluate service adoption and upselling opportunities. |
| Internet Service  | String   | Type of internet service.                                      | Used to analyze internet product adoption and customer preferences. |
| Online Security   | String   | Indicates whether the customer has online security service.    | Measures adoption of value-added security services. |
| Online Backup     | String   | Indicates whether the customer has online backup service.      | Helps identify customers using backup solutions and cross-selling opportunities. |
| Device Protection | String   | Indicates whether the customer has device protection service.  | Used to evaluate adoption of device protection services. |
| Tech Support      | String   | Indicates whether the customer has technical support.          | Measures customer use of support services and service quality. |
| Streaming TV      | String   | Indicates whether the customer subscribes to TV streaming.     | Identifies customers consuming digital entertainment services. |
| Streaming Movies  | String   | Indicates whether the customer subscribes to movie streaming.  | Supports analysis of entertainment service usage. |
| Contract          | String   | Customer's contract type.                                      | Critical for revenue forecasting, customer retention, and churn prediction. |
| Paperless Billing | String   | Indicates whether the customer uses paperless billing.         | Measures adoption of digital billing and operational cost reduction. |
| Payment Method    | String   | Customer's payment method.                                     | Used to analyze payment preferences and payment-related risks. |
| Monthly Charges   | Float64  | Monthly amount charged to the customer.                        | Represents recurring monthly revenue generated by the customer. |
| Total Charges     | String   |  Total amount charged to the customer.                         | Represents the customer's lifetime revenue contribution. |
| Churn Label       | String   | Indicates whether the customer churned.                        | Primary business outcome used to measure customer retention. |
| Churn Value       | Int64    | Numeric representation of churn status.                        | Used in machine learning models and business intelligence reporting. |
| Churn Score       | Int64    | Predicted likelihood of customer churn.                        | Helps prioritize customer retention and proactive intervention strategies. |
| CLTV              | Int64    | Customer Lifetime Value.                                       | Estimates the total financial value a customer brings throughout their relationship with the company. |
| Churn Reason      | String   | Reason the customer left the company.                          | Identifies root causes of churn to improve products, services, and retention strategies. |
